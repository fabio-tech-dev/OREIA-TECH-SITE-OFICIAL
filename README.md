# Oreia Tech

Landing page da **Oreia Tech**, empresa de software e tecnologia que desenvolve sistemas e sites sob medida e faz manutenção de computadores.

## Objetivo

Apresentar os serviços da empresa e levar o visitante a pedir um orçamento por WhatsApp ou Instagram, no PC ou no celular.

## Funcionalidades

- Layout responsivo, pensado primeiro para celular (de 320px a 1920px)
- Menu mobile feito só com CSS
- Navbar com desfoque ao rolar a página
- Atalhos para WhatsApp (com mensagem pronta) e Instagram
- HTML semântico, link "pular para o conteúdo" e foco visível no teclado
- Respeita `prefers-reduced-motion`

## Tecnologias

HTML5, CSS3 e JavaScript Vanilla. Nenhum framework ou biblioteca.

## Identidade visual

| Cor | Hex | Uso |
|---|---|---|
| Preto | `#05070A` | Fundo |
| Azul | `#0066FF` | Gradientes e botões |
| Ciano | `#00D9FF` | Destaques e foco |
| Verde | `#00FF88` | WhatsApp e interações |
| Branco | `#FFFFFF` | Títulos |
| Cinza | `#8B949E` | Textos de apoio |

Tipografia: Chakra Petch (títulos) e Inter (texto). Se estiver sem internet, o navegador usa a fonte do sistema.

## Animações

Todas em CSS: entrada do hero, anel de luz girando atrás da logo, logo flutuando, barra que acende nos serviços e transições de hover.

## Como executar

Abra o arquivo `index.html` direto no navegador. Não precisa instalar nada.

## Antes de publicar

Troque os dados de contato no `index.html`:

- WhatsApp: substitua `5500000000000` pelo número com código do país e DDD (ex.: `5537999999999`)
- Instagram: substitua `oreiatech` pelo perfil real
